# SU7 生成模型轻精修

来源：用户于本次会话提供 `/Users/chenfeiyu/Downloads/su7+3d+model.zip`，内含 Tripo FBX 与四张贴图。保留原文件；未为用户提供的资产另行声明 CC0 或商业授权。

## 交付
- `source/`：原始 FBX 与 4K 贴图。
- `source-import.blend`：原始导入检查版本。
- `refined/su7-refined.blend`：打包纹理、可编辑的轻精修工程；平滑修改器保留未破坏性设置。
- `refined/su7-refined.png`：精修版 Blender 展厅渲染。
- `refined/su7-before-matched.png`：同相机、同灯光的原模型对照。
- `public/models/su7-refined.glb`：网站使用的导出模型（实际路径位于项目根 public/models）。

## 修改
以 Blender 5.2 后台独立工程操作。应用变换，微小距离合并重复顶点，重算法线；平滑着色；Smooth factor 0.12 / 3 iterations 轻度去噪。法线贴图强度降至 0.18；调整粗糙度与清漆，保留原 UV 和细节贴图。运行版贴图降至 2K，原 4K 始终保留在 source。

模型原本仅一个网格、一个材质，未伪造玻璃/车轮独立部件。网站以原蓝色像素推断车身遮罩进行换色，保留中性玻璃、轮胎、牌照和灯具；这是纹理遮罩，不是精确 CAD 车身分区。生成贴图里非车身的蓝色碎片可能仍随之变化，精确分区需要后续手绘遮罩或重拓扑。

## 边界
这是轻修，不是重建。窗框缺口、局部形体波浪、扭曲轮毂、贴图中烘焙的窗户反光仍存在。不会因为面数多就达到汽车 CAD 精度。截图与灯光只辅助检查，不作为实物车膜色准证明。

## 验证
Blender 成功导入、保存并导出；H5 已实际显示 SU7，检查海蓝/红色与哑光切换、玻璃/轮胎保留和截图预览，浏览器检查时无 error/warn。TypeScript、生产构建及配置测试通过。尚未做真实手机长时性能验收；GLB 约 6.7 MiB，超出早期 5 MB 单车目标，需要后续压缩优化。
