# 修改前的生图提示词

以下为本次修改前代码中的完整提示词模板。baseColor 是选择的底色，prompt 是当时输入的描述，aiLayout 是共享分区坐标。未记录历史请求正文，不能仅凭结果图还原那次描述。

```js
 const common=`你是专业汽车车衣平面设计师。输出可直接贴到 3D 车漆表面的二维平面印刷图案。严禁画汽车、车身轮廓、车轮、摄影场景、透视效果、阴影、高光或光照，这些由 3D 引擎实时提供。底色使用 ${v.baseColor}。用户设计要求：${v.prompt}。除用户明确要求外不要添加文字。保持参考元素的主要特征，不要复制参考图的照片背景。`;
 const layout=`输出一张 1024×1024 的整车七面纹理图集。第一张输入图是必须遵守的空白分区模板，后续图片才是用户参考元素。不得把模板当作装饰图。区域坐标以左上角为原点：${aiLayout.map(r=>`${r.name} x=${r.x},y=${r.y},w=${r.width},h=${r.height}`).join('；')}。保持每个区域的位置和尺寸不变；黑色间隔保持原位，不要让图案跨过间隔。右上两块仅填底色 ${v.baseColor}，不是车身图案区域。最终必须擦除全部模板标签、TOP 字样和方向箭头。每个区域的图案上方均朝画布上方。左右侧文字均正向可读，左侧车头朝右，右侧车头朝左。左右侧实际约3:1，引擎盖1.4:1，车顶1.2:1，尾厢2:1，前后保险杠2.4:1，将各面设计缩放存放在指定区域，应用时会恢复比例。只输出这一张完整图集，不要多张图，不要汽车效果图。全车风格和配色统一，关键元素完整置于各区内部并留安全边距。`;
```
