## 可观察的特征

- BRABUS：厚重衬线大写字标；同时有用于车身和轮毂的 B / Double-B 标识，形成文字和徽章分工。
- MANSORY：细致衬线字标，两侧翼状水平线，对称舒展。
- ABT：共用顶部水平关系的几何字母，大斜边和紧凑结构，名称本身就是图形。
- TECHART：极宽、低矮、方折转角的字标，笔画节奏高度统一。
- Singer：签名式手写字标，网页与实车金属字标保持同一轮廓。
- Liberty Walk：官网当前显示哥特风格的 LB 交叠字母；旗下 LB-WORKS、LB★PERFORMANCE 等有不同的命名和视觉应用，不能把其中一款称为整个品牌唯一标识。
- RWB：本次展示官网当前的粗体斜体 RWB。另有 RAUH-Welt BEGRIFF 完整名称的应用；本图没有混用第三方再绘或商品图。

## 对赞车搭的设计启发

先明确品牌气质和稳定的识别核心，再组织元素。建议优先探索中文定制字标，让赞、车、搭三个字共享笔画粗细、转角和比例；单独小图标是辅助标识。品牌关联可先通过有赞红和清晰的品牌署名建立，不需要把所有产品含义同时画进一个图形。字标、小尺寸图标、黑白版本和深浅背景版本应共同构成最小可用体系。

此前两版的问题是将寓意拆成多个插图再拼合，识别层级与轮廓缺少取舍。本次只研究和整理参考，未继续生成赞车搭 Logo。
